# 05 Blog & Changelog

Blog 和 Changelog 使用 Astro Content Layer + MDX。

## Blog

- 内容目录：`src/content/post/`
- 支持 frontmatter、featured、tags、图片、阅读时间。
- 列表页和文章页均已中文化。

## Changelog

- 内容目录：`src/content/changelog/`
- 使用 `version`、`publishDate`、`description`。
- 页面日期格式使用 `zh-CN`。

## 保留英文

`Blog`、`Changelog`、`MDX`、`Content Layer` 等技术或栏目名可保留英文。
