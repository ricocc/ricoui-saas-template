RicoFast v1.0 是模板的稳定版本。前面的 `v0.x` 版本验证了页面结构、内容系统和设计 tokens；v1.0 则把这些内容收束成一个可以直接开工的起点。

这不是单纯堆功能，而是让模板从“预览版”变成一个完整的 SaaS 官网示例。

## 从预览版到稳定版

到 v1.0 为止，模板经历了几个阶段：

- **v0.1**：建立核心营销页面、MDX Blog、Changelog、暗黑模式和基础 UI 组件。
- **v0.2**：优化暗黑模式对比度、动效节奏，并抽出 `BrowserFrame.astro`。
- **v0.3**：迁移 Blog 和 Changelog 到 Astro Content Layer，统一元信息并优化构建。
- **v1.0**：补齐公开页面叙事、Auth 模板、工具页和稳定版示例内容。

模板不只是 section 的集合。页面文案、内容模型、导航和版本记录需要讲同一个故事。

## 页面覆盖

当前页面已经覆盖一个 SaaS 营销站常见的公开面：

- Home、Features、Pricing、About、Contact
- 基于 MDX 的 Blog 和 Changelog
- 用于组件和 token 查看参考的 Elements 页面
- 静态 Sign in 和 Sign up 模板
- 带恢复动作的 404 页面

Header 和 Footer 也已经把这些入口串起来，方便检查整站结构。

## 性能跑分

`v0.3` 的性能工作延续到 v1.0：

- **冷启动构建时间**：CI 上从 21s 降到 14s
- **首页首屏 JS**：AnimatedText 拆分后，gzip 体积从 31KB 降到 24KB
- **图片加载**：Blog 卡片默认 lazy-load

全新安装后，Home、Features 和 Pricing 的 Lighthouse 在 Performance、Accessibility、Best Practices 和 SEO 上都有 95+ 基线。

## 首先该改哪里

如果你从 v1.0 开始，建议按这个顺序：

1. 修改 `src/config/site.js`：品牌、URL、SEO 和社交链接。
2. 通过 `src/styles/global.css` 的 tokens 调整视觉，不要先写临时颜色。
3. 替换首页文案、功能数组、价格内容和 FAQ。
4. 用你自己的文章和 Changelog 替换示例内容。
5. 把静态 Auth 页面接到真实认证服务。

RicoFast 仍然保持静态和 provider-agnostic。你的后端、认证、分析和支付系统，可以在产品需要时再接入。
