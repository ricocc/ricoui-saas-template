## 包含内容

- Home、Features、Pricing、Blog、Changelog、About、Contact、Elements 和 404
- 可复用 section 系统，覆盖 Hero、功能区块、价格卡、对比表、FAQ、技术栈、使用场景和最终 CTA
- 基于 MDX 的 Blog，支持精选文章、分页、tags、阅读进度和目录
- 支持版本 badge 和 MDX 内容的 Changelog 时间线
- 内置无闪烁暗黑模式
- 覆盖手机、平板、笔记本和桌面端的响应式布局
- AOS 滚动入场和少量自定义预设
- Hero 文本错落入场
- 月付 / 年付价格切换示例
- FAQ 折叠项
- Badge 组件
- SEO 元信息、Open Graph、sitemap 和 RSS feed
- 用于查看 tokens、组件和 UI 状态的 Elements 页面

## 为什么仍是 v0.x

这个版本验证了模板形态，但内容模型和视觉故事还需要继续收紧。因此保持在 `v0.x` 版本线，方便团队试用基础能力，而不把它当作最终 API。
