## 迁移到 Content Layer

Blog 和 Changelog 内容迁移到 Astro 的 `glob` loader 与 Content Layer API。旧内容模式被移除，后续接入外部 Markdown、CMS 或其他内容源会更直接。

关键变化：

- `entry.slug` 改为 `entry.id`
- `entry.render()` 改为来自 `astro:content` 的 `render(entry)`
- 静态导入场景使用 `import.meta.glob()`
- `getStaticPaths()` 参数为 Astro v6 做了规范化

## Schema 统一

Blog 和 Changelog frontmatter 使用更接近的结构：

```yaml
title: string
description: string
publishDate: date
version?: string
tags?: string[]
read?: number
img?: string
img_alt?: string
featured?: boolean
```

## 性能收益

- 冷启动构建时间：CI 上从 **21s** 降到 **14s**
- 首页首屏 JS：AnimatedText 拆分后，gzip 体积从 **31KB** 降到 **24KB**
- Blog 卡片默认使用 `loading="lazy"`
- 全新安装后，Home、Features、Pricing 的 Lighthouse 均为 **95+**
