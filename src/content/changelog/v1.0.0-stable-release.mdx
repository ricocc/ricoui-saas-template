## 为什么是 v1.0

`v0.x` 版本已经验证布局、内容、设计 tokens、暗黑模式和性能。`v1.0` 是 RicoFast 从预览模板变成稳定 SaaS 官网模板的节点。

这个版本重点是统一。示例品牌、页面文案、内容模型、导航和工具页现在讲的是同一个故事。

## 主要变化

### 品牌与叙事

- 在页面、元信息、Blog 和 Changelog 中统一使用 RicoFast
- 重新围绕中文 SaaS 团队、独立开发者、AI 工具和开源维护者整理文案
- 清理早期预览版残留表述，统一到稳定版语境

### 页面与路由

- 新增 `/sign-in` 和 `/sign-up` 静态 Auth 模板
- 更新 404 页面，让恢复动作更清楚
- Header 和 Footer 补齐登录、注册和 404 入口
- 保持营销页、Auth 页面、内容页和工具页都由同一套 layout 系统组织

### 内容打磨

- 用 `v0.1`、`v0.2`、`v0.3` 和 `v1.0` 重新梳理发布历史
- 把示例 Blog 改成更接近真实项目文档的中文内容
- 保留 Lighthouse 95+ 的验证口径
- 移除暗示未来版本已存在的旧 roadmap 文案

### 兼容性

- 稳定版内容不引入新的运行时依赖
- 已 fork 的项目可以保留页面结构，逐步替换内容
- 从早期预览版升级时，建议重点检查 `src/config/site.js`、`src/styles/global.css` 和 `src/content/`

## 升级提示

如果你 fork 过 `v0.x` 预览版：

1. 运行 `pnpm install`
2. 检查 `src/content/post/` 和 `src/content/changelog/` 中的新内容结构
3. 更新指向旧文章 slug 的自定义链接
4. 按最终页面集重新检查自己的中文文案

RicoFast `v1.0` 是建议用来开新项目的版本。
